Kindle Series Enabler

Turn on the Kindle library's series grouping on a jailbroken Kindle in a country where Amazon doesn't offer it. Latest release: @VERSION@.

Install with KPM

You need a jailbroken Kindle with KPM installed. With Wi-Fi on, in kterm or over SSH on the Kindle, add this repository once and install:

kpm add-repo @INDEX_URL@
kpm update
kpm install kindle-series-enabler

Uninstall it with kpm uninstall kindle-series-enabler.
